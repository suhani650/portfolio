## Run locally

This is a static, pre-built site, so no installation is needed. Serve the folder with any static server:

```bash
npx serve .
```

Then open the URL shown in the terminal (usually `http://localhost:3000`).

## Deploy on Netlify

1. Push this repository to GitHub.
2. In Netlify, choose **Add new site → Import an existing project** and connect the repo.
3. Leave the **build command** empty and set the **publish directory** to `/` (root).
4. Deploy. The site will be live in a minute.
